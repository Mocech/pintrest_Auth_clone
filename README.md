# Pinterest Auth Clone

A clean and modern authentication interface that replicates the Pinterest login experience. This project demonstrates front-end form design best practices with a focus on user experience and visual aesthetics.

## 🎯 Overview

This repository contains a fully functional authentication UI component built with vanilla HTML, CSS, and JavaScript. It features a professional login modal with email/password authentication and social login options (Google & Facebook).

## ✨ Features

- **Responsive Login Form** - Clean, centered design that works across all devices
- **Password Visibility Toggle** - Eye icon to show/hide password input
- **Social Authentication** - Ready-to-integrate Google and Facebook login buttons
- **Modern UI** - Material-inspired design with smooth interactions
- **Accessibility Focused** - Semantic HTML and keyboard-friendly form inputs
- **No Dependencies** - Pure HTML, CSS, and JavaScript (no frameworks required)

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with flexbox and animations
- **JavaScript (Vanilla)** - Form handling and interactivity
- **Font Awesome** - Icon library for UI elements
